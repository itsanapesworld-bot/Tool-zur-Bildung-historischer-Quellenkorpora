# Lizenzstand

Für den eigenen Projektcode und die Dokumentation wurde noch keine Softwarelizenz festgelegt. Diese Veröffentlichungskopie enthält deshalb keine pauschale Lizenzgewährung und keine behauptete MIT-, Apache- oder andere Open-Source-Lizenz.

Eine Veröffentlichung auf GitHub ist auch ohne Lizenzdatei möglich. Eine gewünschte Erlaubnis zur Nutzung, Änderung und Weiterverteilung muss die Rechteinhaberschaft ausdrücklich festlegen. Eine spätere `LICENSE` muss mit diesem Hinweis und der README abgestimmt werden.

Die Rechte der Python-Abhängigkeiten und gegebenenfalls fremder Inhalte bestehen unabhängig vom eigenen Projektcode. Keine Softwarelizenz dieses Projekts würde automatisch Rechte an ENPA-Zeitungsinhalten erteilen.

Quelle: https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository
